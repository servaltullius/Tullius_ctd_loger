# v0.2.60-rc1 — Address Library 오류 안내와 SKSE가 거부한 플러그인 표시

v0.2.60의 첫 테스트용 프리릴리즈입니다. 기존 파일 일부만 덮지 말고 ZIP 전체를 설치해 주세요.

## 핵심 변경
- 플러그인이 띄운 Address Library 오류 창 때문에 게임이 멈추면, 리포트가 어떤 플러그인을 어떻게 바꿔야 하는지 안내합니다. v0.2.59 실게임 확인 때 SmoothCam.dll이 "Unsupported address library format: 2" 창으로 게임을 멈췄는데, 그때 리포트는 창 내용을 보여주고 "메시지를 따르세요"라고만 했습니다. 이제는 "SmoothCam은 다른 게임 버전용으로 빌드되어 현재 게임(1.6.1170.0)의 Address Library를 지원하지 않습니다. 이 게임 버전용 파일로 바꾸거나 해당 모드를 비활성화하세요"라고 안내합니다.
- 그 실행에서 SKSE가 로드하지 않은 DLL과 사유를 리포트 끝에 참고로 보여줍니다. SKSE는 게임 버전과 맞지 않는 플러그인을 시작할 때 거부하고 skse64.log에 사유를 남깁니다. 거부된 DLL은 실행되지 않으므로 이번 사고의 원인 후보로는 쓰지 않습니다.

## 엔진 변경
- 분석기: modal 대화상자 본문이 CommonLibSSE(-NG)의 Address Library 오류 문구이면 `address_library_issue`(`plugin_incompatible` / `address_library_missing`)를 붙여 요약 문장과 안내를 바꿉니다. 신뢰도와 후보는 바꾸지 않습니다(ADR-0006).
- Helper: 캡처할 때 게임 EXE의 기준 주소를 함께 읽고, `Documents\My Games\Skyrim Special Edition*\SKSE\skse64.log` 중 첫머리 `imagebase`가 같은 로그만 이번 실행의 로그로 씁니다. skse64.log에는 시각 정보가 없어 이전 실행의 로그를 이렇게 걸러냅니다. 결과는 플러그인 스캔의 `skse_log`에 실립니다(ADR-0008).
- 분석기: SKSE가 로드하지 않은 DLL을 `Low` 근거 항목과 체크리스트 맨 끝의 `[SKSE]` 안내로 보여주고, 리포트에 `SkseLog:` 줄을 추가했습니다. 후보, 신뢰도, 요약 문장에는 쓰지 않습니다.
- CI: Windows 빌드가 테스트 링크에서 간헐적으로 실패하면 한 번 다시 빌드합니다. skse64.log 파서용 퍼저를 Linux fuzz 스모크에 추가했습니다.

## 테스트 시 확인할 점
- 게임을 켜고 메인 메뉴든 게임 플레이 중이든 `Ctrl+Shift+F12`로 수동 캡처를 한 번 해 주세요. `SkyrimDiagHelper.log`에 `SKSE log: matched (checked=…, loaded=…, not_loaded=…)` 줄이 찍혀야 합니다. 지금 skse64.log 기준으로는 `checked=322, loaded=320, not_loaded=2`입니다. `matched` 대신 `no_matching_log`나 `not_found`가 나오면 알려 주세요.
- 그 캡처 리포트의 권장 조치 맨 끝에 `[SKSE] 이번 실행에서 SKSE가 로드하지 않은 DLL: msdia140.dll: …, NpcGhostFix.dll: …` 줄이 있고, 이 줄이 다음 조치(맨 앞)로 나오지 않는지 확인해 주세요.
- Address Library 오류 창은 일부러 재현할 필요가 없습니다. 보관 중인 SmoothCam 프리징 덤프로 확인했습니다.
- 아직 실게임에서 확인하지 못한 항목: 모드의 assert로 난 CTD에서 `ExceptionCode`가 `0x80000003`이고 `Module+Offset`이 `CrashLogger.dll`이 아닌지, 덤프가 실패했을 때 실패 위치가 Helper 로그에 남는지.

## 주의사항
- 분석기와 Helper가 바뀌었습니다. 플러그인 코드와 공유 메모리 프로토콜(SharedLayout v4)은 v0.2.59와 같지만 버전 정보가 바뀌므로 ZIP 전체를 교체해 주세요.
- `msdia140.dll`처럼 SKSE 플러그인이 아닌 보조 DLL도 SKSE가 "no version data"로 기록하므로 목록에 나옵니다. 구형 플러그인과 구분할 수 없어 안내에 두 가능성을 함께 적었습니다.
- 이 버전 이전의 캡처에는 SKSE 로그 정보가 없습니다.
- 검수된 실사고 코퍼스가 없어 다른 로거 대비 적중률을 수치로 주장하지 않습니다.
