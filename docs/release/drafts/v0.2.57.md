# v0.2.57 — CrashLogger v1.24 호환성과 로그 화면 개선

## 핵심 변경
- 일반 런타임 `CrashLogger.log`를 실제 크래시 로그로 잘못 선택하지 않도록 CrashLogger SSE v1.24 로그 판별을 강화했습니다.
- 원래 CTD가 기록된 뒤 CrashLogger 내부에서 발생한 후속 예외가 최초 크래시 컨텍스트를 덮지 않도록 보호합니다.
- raw dump의 표면상 위치가 CrashLogger이더라도 페어링된 로그에 행동 가능한 비훅 DLL 프레임이 있으면, 해당 후보를 우선 점검 대상으로 조심스럽게 안내합니다.

## WinUI / 사용성
- 창의 실제 너비를 사용하도록 배치를 보정하고, 좁은 창에서는 핵심 요약 카드가 세로로 쌓입니다.
- 분석 전과 리포트/WCT 없음 상태를 빈 카드 대신 명확한 안내 화면으로 표시합니다.
- 크래시 맥락과 권장 조치를 먼저 읽은 뒤 검토 피드백을 확인하도록 화면 순서를 정리했습니다.
- Tullius 콜스택, DLL 점검 안내, 선행 예외와 시작 오류를 포함한 한국어 문구를 다듬었습니다.

## CrashLogger 호환성
- `Thread dump` 문구만 있는 런타임 로그는 제외하고 실제 `Callstack:` 섹션을 포함한 로그만 크래시 아티팩트 후보로 사용합니다.
- 핸들러 설치 시 CrashLogger 모듈 범위를 미리 기록하며, 크래시 컨텍스트가 이미 고정된 뒤 해당 범위에서 발생한 예외는 최초 컨텍스트를 교체하지 않습니다.
- 개인정보를 제거한 실제 v1.24 형식 fixture로 로그 검색, 직접 오류 프레임과 요약 경로를 회귀 검증했습니다.

## 주의사항
- Crash Logger 프레임과 Tullius 후보는 원인 확정이 아니라 우선 점검 근거입니다. 검토 완료 실사고 코퍼스가 없어 다른 크래시 로거보다 높은 적중률을 수치로 주장하지 않습니다.
- 제공된 기존 v1.24 사고의 재분석으로 분석기 쪽 보정은 확인했지만, 최초 예외 보존은 새 v0.2.57 DLL을 설치한 뒤 발생한 실사고로 현장 검증이 한 번 더 필요합니다.
- 플러그인, Helper, 분석기와 WinUI가 함께 바뀌므로 기존 파일 일부만 덮지 말고 zip 전체를 업데이트해 주세요.
