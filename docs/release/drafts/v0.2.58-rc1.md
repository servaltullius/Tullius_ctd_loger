# v0.2.58-rc1 — CTD 증거 유실 차단과 검증 체계 연결

실제 Skyrim 환경에서 확인하기 위한 테스트용 프리릴리즈입니다. 기존 파일 일부만 덮지 말고 ZIP 전체를 설치해 주세요.

## 핵심 변경
- 덤프 쓰기가 일시적으로 실패해도 사고를 잃지 않도록, 대상 프로세스가 살아 있는 동안 제한된 횟수만큼 그 자리에서 재시도합니다.
- 정상 종료(exit 0)로 분류되는 강한 결함은 빠른 필터와 지연된 프로세스 종료 어느 경로에서도 `SkyrimDiag_CleanExitEvidence_*.json`을 산출물 삭제 전에 남깁니다. JSON은 캡처 당시 결함과 실제 `dump_preserved` 상태를 기록하며, JSON 쓰기가 실패하면 덤프를 자동 보존합니다.
- CrashLogger가 우리보다 늦게 로드되는 로드오더에서도 중첩 예외 억제가 동작하도록, SKSE `kPostLoad` 시점부터 모듈 범위를 다시 조회하고 write-once 규약으로 공개합니다.
- 싱글 스텝, 스레드 이름 설정, `OutputDebugString` 예외를 강한 결함 분류에서 제외해 unsafe `CrashHookMode=2`에서도 정상 알림이 clean-exit 증거 JSON 대상이 되지 않게 했습니다. 기본 Mode 1의 치명적 예외 선택은 기존과 같습니다.

## 빌드 · 검증 체계
- `vcpkg.json`과 `CMakeLists.txt`의 버전이 다르면 릴리스가 실패합니다.
- Linux CI에서 unit, ASan+UBSan, clang-tidy(`WarningsAsErrors`), crash-log parser fuzz를 실행합니다.
- Windows 전용 런타임 테스트와 self-contained WinUI 패키징을 실행합니다.
- `skydiag_quality_corpus_runner`가 raw signal 픽스처를 production `BuildCandidateConsensus()`로 처리하고, 품질 게이트가 후보 순위·상태·신뢰도·점수·기권 및 집계값을 검사합니다. 이는 실사고 정확도 측정이 아니라 candidate-consensus 동작 회귀 감지입니다.
- Windows source/XAML guard는 CRLF를 정규화하고 share-text fixture stdout은 UTF-8로 읽습니다.

## 테스트 시 확인할 점
- 게임을 정상 종료했을 때 불필요한 CTD 리포트가 생성되지 않는지 확인해 주세요.
- 강한 결함 뒤 exit code 0으로 종료되는 사례가 있다면 `SkyrimDiag_CleanExitEvidence_*.json` 생성 여부를 확인해 주세요.
- `PreserveFilteredCrashDumps=1`에서는 JSON의 `dump_preserved`가 `true`이고 덤프가 남는지 확인해 주세요.
- 문제가 발생하면 해당 JSON, 덤프, `SkyrimDiagHelper.log`를 함께 보관해 주세요.

## 주의사항
- **2차 결함 보존 기능은 이번 프리릴리즈에서 제외했습니다.** 안전한 구현에는 `SharedLayout` 버전 상향과 ADR-0004 호환성 검토가 필요합니다. v0.2.57 대비 동시성 위험은 추가되지 않았습니다.
- 검수된 실사고 코퍼스가 없어 다른 크래시 로거 대비 적중률을 수치로 주장하지 않습니다.
- 플러그인, Helper, 분석기와 WinUI가 함께 바뀌므로 기존 파일 일부만 덮지 말고 ZIP 전체를 업데이트해 주세요.
