# v0.2.64 — 1.5.97 시작 직후 CTD 긴급 수정

Skyrim 1.5.97에서 게임을 켜자마자 SkyrimDiag.dll 때문에 CTD가 나던 문제를 고친 긴급 수정 릴리즈입니다. v0.2.62와 v0.2.63에 있던 문제이며, 1.6.x·1.7.104 사용자에게는 동작 변화가 없습니다.

## 고친 것
- **1.5.97 시작 직후 CTD** — 리소스 열기 기록용 후킹이 게임이 연 파일의 이름을 잘못된 위치에서 읽었습니다.
  - 원인: v0.2.62에서 올린 CommonLibSSE-NG v12는 SE와 AE를 함께 빌드할 때 `LooseFileStream`을 AE 배치로 컴파일합니다(앞쪽 `Stream`이 AE 0x18바이트, SE 0x10바이트).
  - 결과: 1.5.97에서는 파일 이름 대신 다른 필드를 포인터로 읽어, 게임이 처음 연 개별 파일에서 크래시가 났습니다(v0.2.62 기준 `SkyrimDiag.dll+0x73294`, Nexus 제보 2건).
  - 수정: 실행 중인 게임이 AE인지 보고 위치(AE `0x18`, SE `0x10`)를 고릅니다.
- 1.6.x·1.7.104에서는 이전과 같은 위치를 읽습니다. 다시 빌드한 플러그인의 기계어로 확인했습니다.

## 실게임에서 확인한 것
- 실게임 미확인: 1.5.97 실행. 이 PC에 1.5.97 설치가 없습니다.
  - 제보된 크래시 주소가 바로 그 읽기 명령(`cmp byte ptr [rcx], al`)이라는 것은 배포된 v0.2.62 DLL을 디스어셈블해 확인했습니다.
  - 그 앞의 파일 이름 읽기가 AE 위치(`[rbx+28h]`)라는 것도 같은 방법으로 확인했습니다.

## 주의사항
- 1.5.97에서 v0.2.62·v0.2.63을 쓰고 있다면 이 버전으로 바꿔 주세요. 임시로는 `SkyrimDiag.ini`에서 `EnableResourceLog=0`으로 두면 이 후킹을 설치하지 않습니다.
- 플러그인만 바뀌었지만 버전을 맞추기 위해 ZIP 전체를 교체해 주세요.
