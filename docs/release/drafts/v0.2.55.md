# v0.2.55 — 정상 종료 CTD 오탐 방지

## 핵심 변경
- SKSE DLL에서 first-chance 접근 위반이 기록되더라도 게임 프로세스가 최종 `exit_code=0`으로 종료되면 처리된 예외로 판정합니다.
- 접근 위반을 "strong exception"으로 분류했다는 이유만으로 정상 종료를 CTD로 되돌리던 우회 경로를 제거했습니다.
- 실제 비정상 종료(`exit_code!=0`)의 덤프 보존, 분석 및 뷰어 동작은 그대로 유지합니다.

## 정상 종료 처리
- 정상 종료가 확인되면 진행 중인 headless 분석과 crash ETW를 중단합니다.
- dump, report, summary, blackbox, WCT, PluginScan 및 incident manifest 등 CTD 산출물을 정리합니다.
- 대기 중인 crash viewer를 취소하고 WER 비정상 종료 안내를 생성하지 않습니다.
- `PreserveFilteredCrashDumps=1`인 경우 원본 dump만 보존하며, 파생 산출물과 capture/viewer latch는 제거합니다.

## 회귀 방지
- `0xC0000005 + InMenu + exit_code=0` 조합을 정상 종료로 분류하는 판정 테스트를 추가했습니다.
- strong shared-memory crash evidence가 남은 프로세스를 실제 `exit_code=0`으로 종료하는 runtime 테스트를 추가했습니다.
- 동일 접근 위반이라도 비정상 종료 코드는 계속 CTD로 보존되는지 검증합니다.

## 주의사항
- 외부 크래시 핸들러가 실제 치명적 CTD의 최종 종료 코드를 0으로 강제하는 매우 드문 환경에서는 해당 사고가 정상 종료로 필터링될 수 있습니다.
- 처리된 first-chance 예외의 원본 dump가 필요하면 `SkyrimDiagHelper.ini`에서 `PreserveFilteredCrashDumps=1`을 설정해 주세요.
