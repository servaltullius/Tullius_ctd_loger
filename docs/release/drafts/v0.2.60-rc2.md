# v0.2.60-rc2 — SKSE 미로드 DLL 목록 정리

rc1 실게임 테스트 결과를 반영한 테스트용 프리릴리즈입니다. 기존 파일 일부만 덮지 말고 ZIP 전체를 설치해 주세요.

## 핵심 변경
- rc1의 skse64.log 기능을 실게임에서 확인했습니다. 수동 캡처 한 번에 Helper 로그에 `SKSE log: matched (checked=322, loaded=320, not_loaded=2)`가 남았고, 리포트에 `SkseLog:` 줄, `[낮음]` 근거 항목, 권장 조치 끝부분의 `[SKSE]` 줄이 나왔습니다. 다음 조치는 바뀌지 않았습니다.
- 그 리포트에서 거부된 두 DLL의 사유가 같아 긴 설명이 두 번 반복됐습니다. 이제 사유가 같은 DLL은 `msdia140.dll, NpcGhostFix.dll: 버전 정보 없음(…)`처럼 한 번에 적습니다.

## 엔진 변경
- 분석기: SKSE가 로드하지 않은 DLL을 사유별로 묶어 근거 항목과 `[SKSE]` 안내에 씁니다. 처음 나온 순서를 지키고, 표시 개수 제한(6개)은 DLL 수로 셉니다. 권장 조치에서는 사유 묶음 사이를 `; `로 나눕니다.

## 테스트 시 확인할 점
- 수동 캡처(`Ctrl+Shift+F12`)를 한 번 하고, 리포트의 `[SKSE]` 줄에 `msdia140.dll, NpcGhostFix.dll: 버전 정보 없음(…)`처럼 설명이 한 번만 나오는지 확인해 주세요.
- 아직 실게임에서 확인하지 못한 항목: 모드의 assert로 난 CTD에서 `ExceptionCode`가 `0x80000003`이고 `Module+Offset`이 `CrashLogger.dll`이 아닌지, 덤프가 실패했을 때 실패 위치가 Helper 로그에 남는지, Address Library 오류 창 안내(보관 덤프 재분석으로만 확인).

## 주의사항
- 분석기만 바뀌었습니다. ZIP 전체를 교체해 주세요.
