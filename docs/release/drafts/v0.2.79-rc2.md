# v0.2.79-rc2 — 플러그인 INI 롱패스 대응, WinUI UX 개선, 분석기·Helper 안정화

v0.2.79-rc1 이후의 변경(PR #331, #332, #333, #334)을 모은 테스트용 프리릴리즈입니다. 플러그인, Helper, 분석기, 뷰어가 모두 바뀌었습니다(SharedLayout protocol v4 그대로, 새 설정 없음). ZIP 전체를 설치해 주세요. MO2에서 새 모드로 설치했다면 이전 버전 모드는 꺼 주세요.

rc1과 버전 번호(0.2.79)가 같아서, rc1로 분석해 둔 덤프는 뷰어가 자동으로 다시 분석하지 않습니다. 새 분석 로직으로 다시 보려면 뷰어에서 덤프를 고른 뒤 "지금 분석"을 눌러 주세요. v0.2.78 이전 버전이 분석해 둔 덤프는 지금처럼 열 때 한 번 다시 분석합니다.

## 한눈에 보기
- **전역 분석기·Helper 신뢰성 버그 5건을 수정했습니다(PR #332).**
  - DirectX 프록시 DLL(`d3d11.dll`, `dxgi.dll`, `d3dcompiler_47.dll`, `d3dx9_42.dll`)이 포함된 프리즈/크래시에서 빠른 답과 메인 스레드 대기 판정이 서로 엇갈리지 않도록 통일했습니다.
  - Crash Logger 로그에 패시브 훅 DLL이나 연속 프레임 패턴이 섞인 경우 원인을 놓치지 않도록 `probable_streak_module`과 패시브 훅 재스캔을 보강했습니다.
  - MO2 긴 경로(260자 초과) 환경에서 Helper 로그 로테이션, 보존 정리(Retention), 덤프 식별 파일 처리가 `PathForIo`로 일관되게 동작합니다.
  - GPU 드라이버(TDR) 이벤트 조회의 상한 경계를 `.9999999Z`로 보정해 크래시 직전 같은 초에 발생한 이벤트가 누락되지 않도록 고쳤습니다.
- **WinUI 덤프 뷰어 사용성과 반응성을 개선했습니다(PR #333).**
  - 상단 전역 상태 바를 추가해 현재 작업 상태와 진행 상황을 어느 탭에서나 바로 확인할 수 있습니다.
  - 핵심 요약(Triage) 영역의 텍스트 선택/복사를 허용하고, Crash Logger 로그 열기와 원시 데이터(Raw Data) 복사 버튼을 바로 배치했습니다.
  - 최근 덤프 목록 클릭 시 불필요하던 1.5초 폴링을 제거하고, 호환성 산출물 폴백 조회, Blackbox 말미 전용 JSON 파싱, 문제 해결 Expander 헤더 표시, 최근 덤프 기본 상한(30개)을 정리했습니다.
- **플러그인 INI 로더, 스냅샷 일관성, 장애 명령 디코더, 사전 점검을 보강했습니다(PR #334).**
  - 플러그인이 작업 디렉터리(CWD) 상대 경로 `GetPrivateProfile*W` 대신 `SkyrimDiag.dll` 옆의 `SkyrimDiag.ini`를 공용 `IniDocument` + `PathForIo`로 직접 읽어 UTF-8 BOM, 비ASCII 경로, MO2 긴 경로에서도 설정이 기본값으로 silently 풀리지 않습니다.
  - 프리즈·수동 캡처·자동 재캡처 덤프도 크래시 캡처와 동일하게 `CaptureStableSharedSnapshot`으로 일관된 공유 메모리 스냅샷을 떠서 기록하며, 재캡처 인시던트 매니페스트에 실제 `state_flags`를 남깁니다.
  - 장애 명령 디코더가 `rep movs*`/`rep stos*` 문자열 복사/초기화 명령과 2/3바이트 VEX(`0xC5`/`0xC4`, `0F` 맵) AVX/AVX2 메모리 명령(32바이트 `ymmword` 및 AVX 정렬 규칙 포함)을 해석합니다.
  - Helper 시작 시 사전 점검(`SkyrimDiag_Preflight.json`)에 형제 바이너리 버전 일치(`BINARY_VERSION_CONSISTENCY`)와 실행 게임 버전용 Address Library 존재 여부(`ADDRESS_LIBRARY_PRESENT`) 항목을 추가했습니다.

## 수정
**플러그인 및 공유 헤더**
- `shared/SkyrimDiagIniText.h`, `helper/include/SkyrimDiagHelper/IniText.h`: Helper 전용이던 휴대형 INI 디코더/파서(UTF-8/UTF-16 BOM/ANSI 지원)를 `shared/SkyrimDiagIniText.h`(`namespace skydiag::ini`)로 승격하고, Helper 헤더는 호환 shim으로 유지했습니다.
- `plugin/src/PluginMain.cpp`: `GetPrivateProfile*W` 기반 CWD 상대 경로 로더를 `GetThisModulePath().parent_path() / L"SkyrimDiag.ini"` + `skydiag::PathForIo` + `skydiag::ini::IniDocument`로 교체하고, 설정 파일 로드 성공 또는 기본값 폴백 경로를 `SkyrimDiag.log`에 기록합니다.

**Helper**
- `Retention.cpp`, `HelperLog.cpp`, `DumpIdentity`: MO2 롱패스 환경에서 파일 존재 확인, 로그 로테이션, 보존 삭제, 덤프 식별 경로가 `PathForIo` 경로 처리로 통일되도록 수정했습니다.
- `FreezeCapture.cpp`, `PendingCrashAnalysis.Execute.cpp`: 프리즈/수동/재캡처 덤프 기록 직전에 `CaptureStableSharedSnapshot`을 호출해 seqlock 일관성 스냅샷을 사용(실패 시 기존 `proc.shm` 폴백)하고, 재캡처 인시던트 매니페스트에 하드코딩 `0u` 대신 캡처된 `dumpShm->header.state_flags`를 기록합니다.
- `CompatibilityPreflight.cpp`: `BINARY_VERSION_CONSISTENCY`(`SkyrimDiag.dll`, `SkyrimDiagDumpToolCli.exe`, `SkyrimDiagDumpToolNative.dll`의 파일 버전과 Helper 버전 대조) 및 `ADDRESS_LIBRARY_PRESENT`(`GameAddressLibraryBytes` 재사용) 점검을 추가했습니다.

**분석기**
- `EvidenceBuilderQuickAnswer.cpp`, `MainThreadWait.cpp`: DirectX 프록시 DLL을 빠른 답과 메인 스레드 대기 분류에서 일관되게 처리합니다.
- `CrashLoggerParseCore.cpp`: `probable_streak_module` 추적 및 패시브 훅 DLL 재스캔을 보강했습니다.
- `GpuDriverEvents.cpp`: 이벤트 로그 시간 범위 상한에 `.9999999Z`를 적용해 같은 초 내 TDR 이벤트 누락을 방지합니다.
- `FaultInstruction.h`, `FaultInstruction.cpp`: `rep movsb/w/d/q` 및 `rep stosb/w/d/q`(이중 메모리 `[rsi]`/`[rdi]` 페이지 폴트 및 `#GP` 비정규 주소 판별)와 2/3바이트 VEX(`0xC5`/`0xC4`, `0F` 맵) AVX/AVX2 메모리 명령(`ymmword` 32바이트, `vcvtps2pd` 16바이트 읽기, `vmovaps`/`vmovapd`/`vmovdqa` 전용 16/32바이트 정렬 판별)을 추가했습니다.

**뷰어 (WinUI)**
- `MainWindow.xaml`, `MainWindow.cs`, `MainWindow.Analysis.cs`, `MainWindowViewModel.cs`: 전역 상태 바, Triage 텍스트 선택, Crash Logger 로그 열기 및 원시 데이터 복사 버튼을 추가하고, 최근 덤프 클릭 시 1.5초 폴링 제거, 호환성 산출물 폴백, Blackbox 말미 전용 JSON 파싱, 문제 해결 Expander 헤더 표시, 최근 덤프 기본 상한(30개)을 반영했습니다.

**CI·테스트(내부)**
- `scripts/ci_apt_install.sh`: Linux CI 패키지 설치 시 `dpkg-query` 사전 확인과 Ubuntu 미러 폴백을 추가해 일시적 리포지토리 장애 내성을 높였습니다(PR #332).
- `.github/actions/windows-setup/action.yml`: `vcpkg-configuration.json` 해시 기반 `actions/cache`와 `--filter=blob:none --no-checkout` + 3회 재시도를 적용했습니다(PR #334).
- 관련 단위/가드 테스트 추가 및 갱신(`fault_instruction_tests`, `plugin_runtime_guard_tests`, `helper_preflight_guard_tests`, `pending_crash_analysis_guard_tests`, `ci_wiring_tests`, WinUI 상태 픽스처 및 XAML 테스트).

## 테스트 시 확인할 점
- MO2에 `v0.2.79-rc2`를 설치해 게임을 실행했을 때 `SkyrimDiag.log`에 `loaded config from ...SkyrimDiag.ini` 줄이 찍히고, `SkyrimDiag_Preflight.json`의 `BINARY_VERSION_CONSISTENCY`와 `ADDRESS_LIBRARY_PRESENT`가 `ok`로 나오는지 확인해 주세요.
- WinUI 뷰어를 열어 상단 전역 상태 바, Triage 텍스트 선택/복사, Crash Logger 로그 열기·원시 데이터 복사 버튼, 최근 덤프 목록 전환 속도가 매끄럽게 동작하는지 확인해 주세요.
- AVX/AVX2(`vmov*`, `vadd*`)나 `rep movs*`/`rep stos*` 명령에서 발생한 크래시가 있다면 리포트의 예외 명령어 줄에 명령과 피연산자가 해석되어 표시되는지 확인해 주세요.
