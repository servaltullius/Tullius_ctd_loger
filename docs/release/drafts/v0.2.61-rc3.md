# v0.2.61-rc3 — 메모리 스냅샷, 문제 모듈 경고, 오브젝트 이름

캡처 당시 메모리(RAM·커밋·VRAM)를 기록하고, 크래시를 가로채는 모듈을 경고하고, 덤프에서 읽은 오브젝트에 이름을 붙인 테스트용 프리릴리즈입니다. 기존 파일 일부만 덮지 말고 ZIP 전체를 설치해 주세요.

## 핵심 변경
- 리포트에 캡처 당시 메모리가 나옵니다. `메모리:` 줄(사용 가능 RAM, 시스템 커밋, 게임 커밋, 워킹셋)과 `GPU:` 줄(게임의 VRAM 사용량과 예산, 예: `VRAM 4.83/22.82 GB(예산 대비 21%)`)입니다. VRAM 예산은 Crash Logger 로그의 `GPU MEMORY`와 같은 값입니다.
- 시스템 커밋이나 VRAM이 한도의 90% 이상이면 `[메모리]` 권장 조치가 붙습니다. 메모리는 모드를 지목하지 않습니다.
- SkyrimCrashGuard처럼 크래시를 가로채 게임을 계속 돌리는 모듈이 로드되어 있으면 `[문제 모듈]`로 알려 줍니다. 이런 모듈은 원래 원인을 숨기고, 이 로거와 Crash Logger가 크래시를 못 잡게 할 수도 있습니다.
- 크래시 덤프에서 읽은 오브젝트에 이름과 기반 오브젝트가 붙습니다. 예: `RCX: Character "Blood Dragon" [0xFF0036F8] (base TESNPC [0x0001D8F6] Skyrim.esm)`.

## 엔진 변경
- 헬퍼: 모든 덤프(크래시, 프리징, 수동)에 게임의 그래픽 어댑터별 VRAM 사용량·예산을 담은 사용자 스트림(`0x1474D`, JSON)을 넣습니다. 커널 그래픽 통계(`D3DKMTQueryStatistics`)를 읽어 0.1ms 안에 끝나고, 함수는 실행 중에 찾아 Wine이나 구형 Windows에서도 헬퍼가 그대로 뜹니다.
- 분석기: 덤프의 SystemMemoryInfo·ProcessVmCounters 스트림(Windows가 자동으로 넣음)과 헬퍼의 GPU 스트림을 읽어 근거 항목, 리포트 `메모리:`/`GPU:` 줄, 요약 JSON `memory`에 넣습니다. 90% 판정은 반올림 전 비율로 하고, PSS 스냅샷 프리징 덤프는 복제본이 커밋에 잡히므로 커밋 판정을 하지 않습니다(ADR-0012).
- 분석기: 덤프의 모듈 목록에 SkyrimCrashGuard.dll이 있으면 근거 항목, `[문제 모듈]` 권장 조치, 리포트 `문제 모듈:` 줄, 요약 JSON `problematic_modules`를 냅니다. 후보가 없으면 다음 조치가 되고 `[재수집]` 안내보다 앞에 옵니다. 후보·버킷·이력에는 영향이 없습니다(ADR-0013).
- 공통 RTTI 해석: 클래스 계층에서 TESFullName 위치를 찾아 이름을 읽고, 레퍼런스는 기반 오브젝트(TESBoundObject인 폼일 때만)를 한 단계 따라갑니다. 이름은 끝까지 읽혔을 때만 씁니다. 요약 JSON `dump_objects`에 `name`과 `base_object`가 추가됩니다(ADR-0010 보강).
- WinUI: `[문제 모듈]`을 "지금 할 일"에 넣습니다.

## 테스트 시 확인할 점
- 게임 중 수동 캡처(Ctrl+Shift+F12)를 한 번 해 주세요. 리포트에 `메모리:`와 `GPU:` 줄이 나오고, `GPU:`에 쓰는 그래픽카드 이름과 예산(전용 VRAM보다 조금 작은 값)이 나오는지 봐 주세요. 작업 관리자의 "전용 GPU 메모리"는 세는 방식이 달라 사용량이 같지 않을 수 있습니다. CTD가 나면 Crash Logger 로그의 `GPU MEMORY`와 비교할 수 있습니다.
- 이미 받아 둔 덤프를 다시 분석하면 `메모리:` 줄이 생깁니다. VRAM(`GPU:` 줄)은 이번 버전으로 찍은 덤프에만 있습니다.
- 아직 실게임에서 확인하지 못한 항목: 덤프 오브젝트와 이름(실제 CTD 필요), 대기 기반 프리징 버킷(실제 프리징 필요), 문제 모듈 경고(SkyrimCrashGuard 미설치), PSS 스냅샷 덤프의 커밋 표시(기본값 꺼짐).

## 주의사항
- 분석기와 헬퍼가 바뀌었습니다. ZIP 전체를 교체해 주세요.
- 레벨드 리스트에서 생긴 액터(대부분의 적)는 기반이 실행 중에 만든 임시 NPC라 이름만 나오고 플러그인은 나오지 않습니다.
- 문제 모듈은 파일 이름이 정확히 같을 때만 찾습니다.
- 검수된 실사고 코퍼스가 없어 다른 로거 대비 적중률을 수치로 주장하지 않습니다.
